# Udderly Ridiculous Farm Life — Homepage Concept

## Build
- Establish the exact supplied colour palette and Barlow Condensed, DM Sans, and sparing Fraunces typography.
- Create a branded white header with desktop navigation, booking action, and a compact mobile menu.
- Compose an asymmetric, photography-led hero using generated placeholder Highland cow imagery and playful graphic accents.
- Build the blue featured-experiences section with four varied photo cards and clear interaction styling.
- Build the editorial Meet the Herd teaser with humorous animal profiles and energetic annotations.
- Add the large blue weekend call-to-action with breakout animal photography, then a practical branded footer.

- Use semantic colour and typography tokens in the global design system.
- Use local generated placeholder farm photography with descriptive alternative text.
- Include route-specific title and social metadata, keyboard focus states, reduced-motion support, and touch-friendly controls.
- Verify the homepage visually at desktop and mobile widths and confirm the current build has no errors.
